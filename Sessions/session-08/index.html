🔄 روابط تبدیل — مبدل زنده

K = C + 273.15
°F = C × 9/5 + 32
°R = (C + 273.15) × 9/5
°C = (F − 32) × 5/9 = K − 273.15

🔬 روش‌های غیرمستقیم اندازه‌گیری دما

⚡ ترموکوپل (اثر سیبک)

اختلاف ولتاژ بین دو فلز غیرهمجنس در محل اتصال. محدوده گسترده، دقت متوسط.

🌡️ ترمیستور

تغییر مقاومت با دما (NTC/PTC). حساسیت بالا، محدوده محدود.

🔌 RTD (PT100)

مقاومت پلاتینی ۱۰۰Ω در ۰°C. دقت بالا، پایدار، گران‌تر.

📡 پیرومتر (تابش)

تابش مادون قرمز، بدون تماس. مناسب اجسام متحرک و داغ.

💡 فیبر نوری

پراکندگی رامان در فیبر. مناسب محیط‌های EMI و فاصله زیاد.

🧠 تخمین دما بدون دماسنج

✋ لمس

تقریبی: خیلی سرد / سرد / گرم / داغ. دقت پایین، وابسته به حس فرد.

👁️ مشاهده فاز

ذوب یخ (۰°C)، جوش آب (۱۰۰°C)، انجماد روغن. مرجع‌های طبیعی.

🔊 سرعت صوت

v = 331 + 0.6×T (m/s). اندازه‌گیری زمان اکو در هوا.

📏 انبساط مواد

ΔL = α × L × ΔT. اندازه‌گیری تغییر طول میله فلزی.

🎨 رنگ اجسام داغ

قرمز (۵۰۰°C) → نارنجی (۸۰۰°C) → زرد (۱۰۰۰°C) → سفید (۱۵۰۰°C).

☀️ محاسبه دمای خورشید (روش غیرمستقیم)

📐 قانون وین

λ_max = b / T که b = 2.898 × 10⁻³ m·K. با یافتن λ_max طیف خورشید (~۵۰۰nm)، دما محاسبه می‌شود.

🔥 قانون استفان-بولتزمن

E = σT⁴ که σ = 5.67 × 10⁻⁸ W/m²K⁴. با اندازه‌گیری تابش کل، دما محاسبه می‌شود.

🌈 طیف‌سنجی

بررسی خطوط جذبی طیف خورشید و مقایسه با طیف‌های آزمایشگاهی.

محاسبه: λ_max ≈ 500nm → T = b / λ_max = 2.898×10⁻³ / 500×10⁻⁹ ≈ 5796 K ≈ ۵۵۲۳°C
نتیجه: دمای سطح خورشید تقریباً ۵,۵۰۰ تا ۵,۸۰۰ کلوین است.

🔧 نکات و تجربه‌های اتصال سنسور دما

۱. مقاومت Pull-up

برای DS18B20 حتماً ۴.۷kΩ بین VCC و DATA قرار دهید.

۲. طول سیم

I2C حداکثر ۱ متر، 1-Wire حداکثر ۱۰۰ متر. برای فواصل بیشتر از تقویت‌کننده.

۳. نویز

کابل شیلددار + خازن ۰.۱µF نزدیک سنسور. زمین مشترک.

۴. کالیبراسیون

مقایسه با دماسنج مرجع در ۰°C (یخ) و ۱۰۰°C (بخار).

۵. عایق‌بندی

هیت‌شرینک برای محیط مرطوب. رزین اپوکسی برای صنعتی.

۶. تغذیه

منبع تغذیه تمیز، جدا از موتور/رله. خازن ۱۰۰µF روی تغذیه.

پروژه ۱

LM35 روی Serial Monitor

خواندن دمای LM35 و نمایش روی سریال. ساده‌ترین روش اندازه‌گیری دما با Arduino.

🎯 هدف: اندازه‌گیری دما و تبدیل ADC به °C.
// LM35 Temperature Sensor const int lm35Pin = A0; void setup() { Serial.begin(9600); } void loop() { int raw = analogRead(lm35Pin); float voltage = raw * (5.0 / 1023.0); float tempC = voltage * 100.0; Serial.print("Temp: "); Serial.print(tempC); Serial.println(" C"); delay(1000); }
پروژه ۲

DHT22 روی نمایشگر OLED

نمایش دما و رطوبت روی OLED. ترکیب دو مهارت جلسه ۷ و ۸.

🎯 هدف: نمایش دما و رطوبت به صورت زنده.
#include <Wire.h> #include <Adafruit_SSD1306.h> #include <DHT.h> #define DHTPIN 2 #define DHTTYPE DHT22 DHT dht(DHTPIN, DHTTYPE); Adafruit_SSD1306 display(128, 64, &Wire, -1); void setup() { dht.begin(); display.begin(SSD1306_SWITCHCAPVCC, 0x3C); display.clearDisplay(); } void loop() { float t = dht.readTemperature(); float h = dht.readHumidity(); display.clearDisplay(); display.setTextSize(2); display.setTextColor(WHITE); display.setCursor(0, 10); display.print(t, 1); display.print(" C"); display.setCursor(0, 40); display.print(h, 1); display.print(" %"); display.display(); delay(2000); }
پروژه ۳

DS18B20 چندسنسوری

چند سنسور DS18B20 روی یک سیم با آدرس‌دهی. مناسب پایش چندنقطه‌ای.

🎯 هدف: خواندن چند سنسور از یک باس 1-Wire.
#include <OneWire.h> #include <DallasTemperature.h> #define ONE_WIRE_BUS 2 OneWire oneWire(ONE_WIRE_BUS); DallasTemperature sensors(&oneWire); void setup() { Serial.begin(9600); sensors.begin(); Serial.print("Found: "); Serial.println(sensors.getDeviceCount()); } void loop() { sensors.requestTemperatures(); for (int i = 0; i < sensors.getDeviceCount(); i++) { Serial.print("Sensor "); Serial.print(i); Serial.print(": "); Serial.print(sensors.getTempCByIndex(i)); Serial.println(" C"); } delay(2000); }
