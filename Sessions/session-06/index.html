📜 تاریخچه و اصول ADC

ADC (Analog-to-Digital Converter) یک قطعه‌ی الکترونیکی است که سیگنال پیوسته (ولتاژ) را به عدد دیجیتال تبدیل می‌کند.

۱۹۲۰
اولین ADC

پل رینی، مهندس آمریکایی، اولین ADC مکانیکی را برای انتقال تصویر تلگراف ساخت.

۱۹۴۰
ADC لامپی

در جنگ جهانی دوم، ADCهای لامپی برای رمزگشایی سیگنال‌های رادار استفاده شدند.

۱۹۶۰
ADC مجتمع

با اختراع مدار مجتمع (IC)، ADCها کوچک و ارزان شدند.

۲۰۰۰
ADC CMOS

ADCهای CMOS با سرعت بالا و مصرف کم، در همه‌ی دستگاه‌ها حاضر شدند.

📶 ADC ۱۰ بیتی — چگونه کار می‌کند؟

ADC ۱۰ بیتی یعنی ولتاژ ۰ تا ۵ ولت به ۲۱۰ = ۱۰۲۴ پله تقسیم می‌شود.

مقدار ADC = (ولتاژ / ۵) × ۱۰۲۳

ولتاژ مقدار ADC درصد
۰ ولت۰۰٪
۱.۲۵ ولت۲۵۶۲۵٪
۲.۵ ولت۵۱۲۵۰٪
۳.۷۵ ولت۷۶۸۷۵٪
۵ ولت۱۰۲۳۱۰۰٪

💡 ترفندهای کامیونیتی برای ADC

۱

۱۰ بار بخوانید و میانگین بگیرید. نویز تصادفی کاهش می‌یابد.

int sum = 0; for(int i=0; i<10; i++) { sum += analogRead(A0); delay(10); } int avg = sum / 10;

۳

۴

۱۰۲۴ بار بخوانید و جمع بزنید. دقت ۱۰ بیت به ۱۳ بیت می‌رسد!

۵
ولتاژ مرجع خارجی

برای دقت بالاتر، از ولتاژ مرجع دقیق (مثل TL431) استفاده کنید.

🤚 پروژه ویژه: کنترل LED با دست (MediaPipe)

ایده چیست؟

به جای چرخاندن پتانسیومتر با دست، از فاصله‌ی دو انگشت اشاره استفاده می‌کنیم:

نزدیک‌تر = LED روشن‌تر
دورتر = LED کم‌نورتر

کتابخانه MediaPipe از گوگل، دست را در تصویر دوربین تشخیص می‌دهد و ۲۱ نقطه‌ی آن را پیدا می‌کند.

📟 کد Arduino (دریافت PWM از Serial)

// ============================================ // پروژه: کنترل LED با MediaPipe (Arduino) // مدرس: دکتر مسعود گوهری‌منش // ============================================ const int LED_PIN = 9; // پین PWM void setup() { Serial.begin(9600); // ارتباط سریال pinMode(LED_PIN, OUTPUT); // تنظیم پین خروجی Serial.println("Arduino Ready"); } void loop() { if (Serial.available() > 0) { int pwm = Serial.parseInt(); // خواندن عدد pwm = constrain(pwm, 0, 255); // محدود کردن analogWrite(LED_PIN, pwm); // تنظیم روشنایی } }

🐍 کد Python (MediaPipe → Serial)

# ============================================ # پروژه: کنترل LED با MediaPipe (Python) # نیازمندی‌ها: # pip install opencv-python mediapipe pyserial numpy # ============================================ import cv2 import mediapipe as mp import serial import numpy as np import time # ==== تنظیمات سریال ==== SERIAL_PORT = "COM3" # ویندوز: COM3 | لینوکس: /dev/ttyUSB0 BAUD_RATE = 9600 try: arduino = serial.Serial(SERIAL_PORT, BAUD_RATE, timeout=1) time.sleep(2) print(f"✅ متصل به {SERIAL_PORT}") except: print("⚠️ Arduino پیدا نشد") arduino = None # ==== MediaPipe ==== mpHands = mp.solutions.hands hands = mpHands.Hands( max_num_hands=2, min_detection_confidence=0.7, min_tracking_confidence=0.7 ) mpDraw = mp.solutions.drawing_utils # ==== دوربین ==== cap = cv2.VideoCapture(0) prev_pwm = -1 while True: success, img = cap.read() if not success: break img = cv2.flip(img, 1) imgRGB = cv2.cvtColor(img, cv2.COLOR_BGR2RGB) results = hands.process(imgRGB) if results.multi_hand_landmarks and len(results.multi_hand_landmarks) == 2: hand1 = results.multi_hand_landmarks[0] hand2 = results.multi_hand_landmarks[1] # نقطه ۸ = نوک انگشت اشاره h1 = hand1.landmark[8] h2 = hand2.landmark[8] # محاسبه فاصله dist = np.sqrt( (h1.x - h2.x)**2 + (h1.y - h2.y)**2 ) # نرمال کردن (۰-۱) distance_norm = min(dist / 0.5, 1.0) # نزدیک‌تر = PWM بیشتر pwm = int((1 - distance_norm) * 255) pwm = max(0, min(255, pwm)) # ارسال به Arduino if arduino and abs(pwm - prev_pwm) > 5: arduino.write(f"{pwm}\n".encode()) prev_pwm = pwm # رسم دست‌ها for handLms in results.multi_hand_landmarks: mpDraw.draw_landmarks(img, handLms, mpHands.HAND_CONNECTIONS) # خط بین انگشتان h, w, c = img.shape x1, y1 = int(h1.x * w), int(h1.y * h) x2, y2 = int(h2.x * w), int(h2.y * h) cv2.line(img, (x1, y1), (x2, y2), (0, 255, 255), 3) cv2.putText(img, f"PWM: {pwm}", (20, 50), cv2.FONT_HERSHEY_SIMPLEX, 1.2, (0, 255, 255), 3) cv2.imshow("MediaPipe LED", img) if cv2.waitKey(1) & 0xFF == ord('q'): break cap.release() cv2.destroyAllWindows() if arduino: arduino.close()
