📏 یکاها و استانداردهای سیگنال

پاسکال (Pa)

یکای SI = ۱ N/m². در صنعت: kPa و MPa

بار (bar)

یکای متری صنعتی. ۱ bar = ۱۰⁵ Pa ≈ ۱ atm

psi

پوند بر اینچ مربع. ۱ atm = ۱۴.۷ psi

mmHg / Torr

یکای پزشکی و خلأ. ۱ atm = ۷۶۰ mmHg

استاندارد ۴-۲۰mA

۴mA = صفر زنده (تشخیص قطع سیم)
۲۰mA = حداکثر مقیاس
مزیت: مصونیت در برابر نویز، انتقال تا فواصل طولانی

استاندارد ۳-۱۵psi

۳psi = صفر زنده
۱۵psi = حداکثر مقیاس
کاربرد: محیط‌های انفجاری، پالایشگاه

⚙️ فشارسنج‌های مکانیکی قدیمی (۱)

لوله بوردون (Bourdon)

لوله فلزی بیضوی C/حلزونی/مارپیچ. با فشار، باز شده و عقربه را حرکت می‌دهد. محدوده: ۰.۵ تا ۷۰۰۰ bar.

دیافراگمی (Diaphragm)

دیسک متموج فلزی/سیلیکونی. مناسب سیالات ویسکوز و خورنده. فشارهای پایین تا متوسط.

فانوسی (Bellows)

محفظه آکاردئونی. جابجایی خطی بزرگ. مناسب فشارهای پایین و تفاضلی + LVDT.

🧪 فشارسنج‌های مکانیکی قدیمی (۲) — مانومتر و عقربه‌ای

مانومتر U-شکل توریچلی

ستون جیوه در لوله U. اختلاف ارتفاع = فشار. ساده، دقیق، اما بزرگ و شکننده.

فشارسنج عقربه‌ای (Aneroid)

دیافراگم/فانوس + فنر + عقربه. کم‌هزینه، قابل حمل. نیاز به کالیبراسیون دوره‌ای.

فشارسنج جیوه‌ای

دقیق‌ترین استاندارد مرجع. اما سمیت جیوه → حذف تدریجی از پزشکی.

⚡ سنسورهای الکتریکی نوین (۱)

استرین‌گیج (Strain Gauge)

تغییر مقاومت با کرنش. R = ρL/A. سیم نازک ۰.۰۲۵mm از کنستانتان.

پل وتستون (Wheatstone)

۴ استرین‌گیج در پل. خروجی mV متناسب با فشار. جبران دما.

پیزورزیستیو MEMS

استرین‌گیج سیلیکونی روی دیافراگم. حساسیت ۱۰۰ برابر فلز. TPMS، MAP، MPX.

🌊 سنسورهای الکتریکی نوین (۲)

خازنی (Capacitive)

C = εA/d. دیافراگم متحرک + صفحه ثابت. پایداری بالا، فشارهای پایین.

پیزوالکتریک (Piezoelectric)

کوارتز + فشار → بار الکتریکی. فقط دینامیکی (احتراق، ضربه).

لودسل (Load Cell)

تبدیل نیرو/وزن به mV. دینامومتر ۳ محوره (Kistler 9255B).

فیبر نوری

پراکندگی رامان در فیبر. مناسب EMI و فواصل زیاد.

🔧 نکات و تجربه‌های اتصال سنسور فشار

۱. تغذیه ۳.۳V

BMP280 با ۳.۳V کار می‌کند. ماژول‌های آماده رگولاتور دارند، اما IC خام نیاز به ۳.۳V دارد.

۲. I2C Pull-up

مقاومت ۴.۷kΩ روی SCL و SDA. اکثر ماژول‌ها دارند، اما چک کنید.

۳. نویز

خازن ۰.۱µF نزدیک سنسور. کابل شیلددار برای فواصل طولانی.

۴. کالیبراسیون

مقایسه با فشارسنج مرجع. تنظیم offset در کد.

۵. عایق‌بندی

هیت‌شرینک برای محیط مرطوب. رزین اپوکسی برای صنعتی.

۶. مکان‌یابی

دور از موتور/رله. جهت سنسور (پورت فشار به پایین برای مایعات).

🚗 سیستم TPMS — فشار تایر، مصرف سوخت و سلامت

مستقیم (Direct TPMS)

سنسور فشار + دما + فرستنده رادیویی + باتری روی رینگ. دقت بالا، هشدار سریع (<۵ ثانیه)، پایش زاپاس.

غیرمستقیم (Indirect)

بدون سنسور فشار. با سنسور سرعت ABS + فیلتر کالمن، تغییر شعاع تایر را تخمین می‌زند. ارزان‌تر.

ایستگاه‌های CGS/TBS گاز

دبی ونتوری

ΔP ∝ Q². لوله ونتوری، نازل، صفحه اوریفیس. اندازه‌گیری دبی از افت فشار.

سطح هیدروستاتیک

P = ρgh. روش دمنده هوا برای مایعات خورنده بدون تماس.

TPMS و MAP

فشار تایر و فشار منیفولد موتور. سنسورهای MEMS پیزورزیستیو.

پروژه ۱

BMP280 روی Serial Monitor

خواندن فشار و دما از BMP280 و نمایش روی سریال. پایه‌ای‌ترین روش.

🎯 هدف: اندازه‌گیری فشار و محاسبه ارتفاع.
// BMP280 Pressure & Temperature #include <Wire.h> #include <Adafruit_BMP280.h> Adafruit_BMP280 bmp; void setup() { Serial.begin(9600); if (!bmp.begin(0x76)) { Serial.println("BMP280 not found!"); while(1); } } void loop() { float p = bmp.readPressure() / 100.0; float t = bmp.readTemperature(); float alt = bmp.readAltitude(1013.25); Serial.print("P: "); Serial.print(p); Serial.println(" hPa"); Serial.print("T: "); Serial.print(t); Serial.println(" C"); Serial.print("Alt: "); Serial.print(alt); Serial.println(" m"); delay(2000); }

BMP280 روی OLED (فشار + ارتفاع)

نمایش فشار، دما و ارتفاع روی OLED. ترکیب جلسه ۷ و ۹.

🎯 هدف: ساخت یک ایستگاه هواشناسی مینیاتوری.
#include <Wire.h> #include <Adafruit_SSD1306.h> #include <Adafruit_BMP280.h> Adafruit_SSD1306 display(128, 64, &Wire, -1); Adafruit_BMP280 bmp; void setup() { display.begin(SSD1306_SWITCHCAPVCC, 0x3C); bmp.begin(0x76); display.clearDisplay(); } void loop() { float p = bmp.readPressure() / 100.0; float t = bmp.readTemperature(); float alt = bmp.readAltitude(1013.25); display.clearDisplay(); display.setTextSize(1); display.setTextColor(WHITE); display.setCursor(0, 0); display.print("P: "); display.print(p, 1); display.println(" hPa"); display.print("T: "); display.print(t, 1); display.println(" C"); display.print("Alt: "); display.print(alt, 0); display.println(" m"); display.display(); delay(2000); }
پروژه ۳

هشدار فشار بالا با LED و بازر

اگر فشار از آستانه عبور کرد، LED روشن و بازر فعال شود. کاربرد ایمنی صنعتی.

🎯 هدف: پیاده‌سازی سیستم هشدار فشار.
#include <Wire.h> #include <Adafruit_BMP280.h> Adafruit_BMP280 bmp; const int LED_PIN = 8; const int BUZZER_PIN = 9; const float THRESHOLD = 1020.0; void setup() { pinMode(LED_PIN, OUTPUT); pinMode(BUZZER_PIN, OUTPUT); bmp.begin(0x76); Serial.begin(9600); } void loop() { float p = bmp.readPressure() / 100.0; Serial.print("P: "); Serial.println(p); if (p > THRESHOLD) { digitalWrite(LED_PIN, HIGH); tone(BUZZER_PIN, 1000); Serial.println("ALERT: High Pressure!"); } else { digitalWrite(LED_PIN, LOW); noTone(BUZZER_PIN); } delay(1000); }
