۲ سیم: SDA (داده) + SCL (کلاک)

✓ فقط ۲ سیم
✓ چند دستگاه با آدرس
✓ استاندارد OLED
✗ کندتر از SPI

🟡 SPI

۴ سیم: MOSI + MISO + SCK + CS

✓ بسیار سریع
✓ مناسب نمایشگرهای بزرگ
✗ ۴ سیم
✗ هر دستگاه CS جداگانه

🏷️ آدرس‌دهی I2C — هر دستگاه یک آدرس

در پروتکل I2C، هر دستگاه یک آدرس ۷ بیتی منحصر به فرد دارد.

// آدرس‌های رایج I2C // OLED SSD1306 → 0x3C یا 0x3D // LCD PCF8574 → 0x27 یا 0x3F // BMP280 → 0x76 یا 0x77 // MPU6050 → 0x68 #include <Wire.h> void setup() { Serial.begin(9600); Wire.begin(); } void loop() { for(byte addr = 0; addr < 127; addr++) { Wire.beginTransmission(addr); if (Wire.endTransmission() == 0) { Serial.print("Found: 0x"); Serial.println(addr, HEX); } } delay(5000); }

پروژه ۱

نمایشگر LCD 16x2 با I2C

راه‌اندازی LCD کاراکتری با ماژول I2C. مقایسه عملی با OLED و درک تفاوت‌های کاربرد.

🎯 هدف: نمایش متن «Ola Mundo!» روی LCD 16x2.
باز کردن پروژه در Wokwi
کد را از تب کناری کپی کنید و در Wokwi جای‌گذاری کنید.
#include <Wire.h> #include <LiquidCrystal_I2C.h> LiquidCrystal_I2C lcd(0x27, 16, 2); void setup() { lcd.init(); lcd.backlight(); Serial.begin(9600); lcd.setCursor(0, 0); lcd.print("Ola Mundo!"); lcd.setCursor(0, 1); lcd.print("Sou a IHM"); Serial.println("LCD ativo!"); } void loop() {}
پروژه ۲

نمایش دمای DHT22 روی LCD

خواندن دما از سنسور DHT22 و نمایش آن روی LCD 16x2. کاربرد واقعی نمایشگر در سیستم‌های اندازه‌گیری.

🎯 هدف: ساخت یک دماسنج دیجیتال ساده.
باز کردن پروژه در Wokwi
کد را از تب کناری کپی کنید.
#include <Wire.h> #include <LiquidCrystal_I2C.h> #include <DHT.h> #define DHTPIN 2 #define DHTTYPE DHT22 DHT dht(DHTPIN, DHTTYPE); LiquidCrystal_I2C lcd(0x27, 16, 2); void setup() { Serial.begin(9600); dht.begin(); lcd.init(); lcd.backlight(); } void loop() { float t = dht.readTemperature(); lcd.clear(); lcd.setCursor(0, 0); lcd.print("Temp: "); lcd.print(t, 1); lcd.print(" C"); delay(2000); }
پروژه ۳

نمایش متن روی OLED (Hello World)

راه‌اندازی اولیه OLED SSD1306 و نمایش متن. پایه‌ای برای تمام پروژه‌های گرافیکی.

🎯 هدف: نمایش «Hello» و «Arduino» روی OLED.
باز کردن پروژه در Wokwi
این پروژه شامل سنسور خاک است؛ کد OLED را می‌توانید اقتباس کنید.
#include <Wire.h> #include <Adafruit_GFX.h> #include <Adafruit_SSD1306.h> #define SCREEN_WIDTH 128 #define SCREEN_HEIGHT 64 Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1); void setup() { display.begin(SSD1306_SWITCHCAPVCC, 0x3C); display.clearDisplay(); display.setTextSize(2); display.setTextColor(SSD1306_WHITE); display.setCursor(10, 15); display.println("Hello"); display.setCursor(10, 40); display.println("Arduino"); display.display(); } void loop() {}
پروژه ۴

اسکنر آدرس I2C

پیدا کردن آدرس I2C دستگاه‌های متصل. مهارت حیاتی برای عیب‌یابی مدارات.

🎯 هدف: یادگیری اسکن و شناسایی دستگاه‌های I2C.
باز کردن پروژه در Wokwi
کد را کپی کنید و در Wokwi اجرا کنید.
#include <Wire.h> void setup() { Serial.begin(9600); Wire.begin(); Serial.println("I2C Scanner"); } void loop() { byte count = 0; for (byte addr = 1; addr < 127; addr++) { Wire.beginTransmission(addr); if (Wire.endTransmission() == 0) { Serial.print("Found: 0x"); Serial.println(addr, HEX); count++; } } Serial.print("Total: "); Serial.println(count); delay(5000); }
پروژه ۵

داشبورد سنسور خاک با OLED

پروژه‌ای کامل‌تر: نمایش درصد رطوبت خاک، وضعیت (DRY/OK/WET) و حتی تصویر گیاه روی OLED.

🎯 هدف: ترکیب سنسور آنالوگ، OLED و منطق شرطی در یک پروژه واقعی.
باز کردن پروژه در Wokwi
این پروژه کامل‌ترین نمونه در این جلسه است.
// بخش OLED پروژه سنسور خاک #include <Adafruit_SSD1306.h> #define SCREEN_WIDTH 128 #define SCREEN_HEIGHT 64 Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1); void showOnOLED(int percent, int raw) { display.clearDisplay(); display.setTextSize(2); display.setCursor(0, 16); display.print(percent); display.println("%"); display.setTextSize(1); display.setCursor(0, 40); display.print("Raw:"); display.println(raw); if (percent < 30) display.println("DRY!"); else if (percent < 60) display.println("OK"); else display.println("WET"); display.display(); }

🌐 شبیه‌سازهای جایگزین: Velxio و Scratchboard

Wokwi (پیشنهادی)

کامل‌ترین شبیه‌ساز آنلاین Arduino با پشتیبانی از OLED، LCD، DHT22 و کتابخانه‌های Adafruit. کدهای واقعی Arduino در مرورگر اجرا می‌شوند [citation:3].

Velxio

شبیه‌ساز رایگان و متن‌باز. کد Arduino را با arduino-cli کامپایل می‌کند و روی یک پردازنده AVR8 شبیه‌سازی‌شده اجرا می‌کند. از OLED و LCD پشتیبانی می‌کند [citation:4][citation:10].

Scratchboard

نسخه ۲ با موتور شبیه‌سازی WASM (Rust) بازنویسی شده. از LCD1602، LCD2004 و SSD1306 OLED پشتیبانی می‌کند. رایگان برای شروع، نسخه Maker با ۷ دلار در ماه [citation:5].

💡 توصیه نهایی: برای این جلسه از Wokwi استفاده می‌کنیم چون هماهنگ با جلسات قبل است و کدهای آن مستقیماً روی سخت‌افزار واقعی هم کار می‌کنند. Velxio و Scratchboard گزینه‌های خوبی برای کاوش بیشتر هستند.
