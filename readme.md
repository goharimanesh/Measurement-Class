## 📚 درباره دوره

این مخزن شامل **مجموعه کامل لکچرهای تعاملی درس «سیستم‌های اندازه‌گیری و کنترل»** است که به‌صورت **پروژه‌محور** و با تکیه بر ابزارهای عملی **Arduino** و **ESP32-CAM** طراحی شده است.

هر جلسه به‌صورت یک **فایل HTML تعاملی** ارائه می‌شود که شامل:

- 🎨 **اسلایدهای حرفه‌ای** با انیمیشن و افکت‌های بصری
- 🔊 **افکت‌های صوتی تعاملی** و موسیقی پس‌زمینه
- 🎮 **شبیه‌سازهای تعاملی** (PWM، ADC، سیگنال، میکروفون)
- 📊 **دیاگرام‌های SVG انیمیت‌شده**
- 🖼️ **تصاویر مفهومی مینیمال**
- 📝 **تمرین‌های کلاسی دقیق** به همراه چالش‌های خلاقانه
- 🎯 **پروژه‌های عملی گام‌به‌گام**
